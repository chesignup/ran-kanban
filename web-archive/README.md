# Web version archive (retired 2026-10-17)

Archive of the retired web/PWA version of "המשימות של רן", snapshot of `main` at commit 5d20981 (v0.1.5), taken 2026-10-17.

The web version was never deployed publicly (no GitHub Pages, no gh-pages branch, no external host). It is retired; the app is distributed only as the Android APK (GitHub Releases).

Files: `index.html`, `manifest.json`, `sw.js`, `Sortable.min.js`, `icon.png`, `icon192.png`.
To view locally: serve this folder with any static server (e.g. `npx serve web-archive`).

Note: the root `index.html` (and siblings) remain the source for the Android build (`npm run www` copies them into `www/`). Do not delete them.
